# Honors Societies Club

A durable, mobile-friendly website for the Honors Societies Club affiliated with the East Los Angeles College Honors Program.

The website publishes automatically through GitHub Pages whenever approved changes are added to the `main` branch.

Public website: https://zcheng31.github.io/honorssocietiesclub/

See `MAINTENANCE.md` for the plain-language semester update, backup, privacy, and ownership-transfer guide.
